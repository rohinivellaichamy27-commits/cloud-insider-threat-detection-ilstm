# Cloud Insider Threat Detection Using ILSTM, CUDB and Blockchain

## Research Publication

**Enhancing Cloud Insider Threat Detection Using ILSTM with Comparable User Behavior and Blockchain**

Published in IEEE Conference Proceedings.

## Research Overview

This research proposes a Blockchain-Assisted Improved Long Short-Term Memory (ILSTM) framework for detecting insider threats in cloud environments.

The framework uses Comparable User Behavior Database (CUDB), a Comparison Layer, and blockchain-based trust auditing to identify anomalous activities and securely maintain user activity records.

## Key Results

- Dataset: 20,000 synthetic cloud activity records
- Detection Accuracy: 96%
- False Positive Rate: 5%
